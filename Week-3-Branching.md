# Week 3: Git Branching and Merge Conflicts

## 1. Introduction

Git branching allows developers to work on different features without changing the main branch.

## 2. Objectives

The objectives of this week's activities are:

- To understand Git branching.
- To create and manage branches.
- To learn how to switch between branches.
- To understand merge conflicts.
- To practice merging branches.

## 3. What is a Git Branch?

A Git branch is a separate line of development.
It allows developers to work on new features independently.

## 4. Important Git Branch Commands

- git branch: Display available branches.
- git switch branch-name: Switch to another branch.
- git switch -c branch-name: Create and switch to a new branch.
- git merge branch-name: Merge another branch into the current branch.
- git branch -d branch-name: Delete a branch.

## 5. Merge Conflicts

A merge conflict happens when Git cannot automatically combine changes from different branches.

Developers must review the conflicting changes and resolve them manually.

## 6. Learning Outcome

I learned how Git branches work and how developers use them to manage separate development tasks.
