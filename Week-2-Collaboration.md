# Week 2: GitHub Collaboration

## 1. Introduction

This week focuses on collaboration using Git and GitHub. I learned how developers work together using branches, commits, and pull requests.

## 2. Objectives

- Understand Git branches.
- Create and manage branches.
- Learn how to commit changes.
- Understand Pull Requests.
- Practise collaborative development.

## 3. Branch Management

A branch allows developers to work on new features without changing the main branch.

Branch Name: feature/week-2-collaboration

## 4. Commit and Push

Git commits save project changes. Git push uploads local commits to GitHub.

## 5. Pull Requests

A Pull Request allows developers to propose changes and review them before merging into the main branch.

## 6. Learning Outcome

This activity helps me understand how GitHub supports teamwork and collaborative software development.
